Assignment name  : ft_list_count_if
Expected files   : ft_list_count_if.c, ft_list.h
Allowed functions:
--------------------------------------------------------------------------------

Write a function that returns the number of elements of the list for which the
function f, applied to the data of the element, returns a value different from
0.

It must be declared as follows:

int	ft_list_count_if(t_list *begin_list, int (*f)(void *));

You must use the following structure, and turn it in as a file called
ft_list.h:

typedef struct		s_list
{
	struct s_list	*next;
	void			*data;
}					t_list;

If the list is empty, the function returns 0. The list must not be modified.

Example:

With a list whose data are the strings "chat", "", "chien" and "" (in this
order), and a function f that returns the length of the string it receives,
ft_list_count_if returns 2.
