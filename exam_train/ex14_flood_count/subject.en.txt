Assignment name  : flood_count
Expected files   : flood_count.c, t_point.h
Allowed functions: malloc, free
--------------------------------------------------------------------------------

Write a function that takes a char ** as a 2-dimensional array of char, a
t_point as the dimensions of this array, and a t_point as a starting point.

The function returns the number of cells of the zone that contains begin. A
zone is a group of cells holding the same character, connected horizontally or
vertically (not diagonally), and delimited by other characters or by the
boundary of the array.

Unlike flood_fill, the array must be exactly the same as before when the
function returns.

tab[y][x] is the cell at column x of line y. The array only contains printable
characters. If begin is outside of the array, the function returns 0.

It must be declared as follows:

int	flood_count(char **tab, t_point size, t_point begin);

You must use the following structure, and turn it in as a file called
t_point.h:

typedef struct	s_point
{
	int			x;
	int			y;
}				t_point;

Example, with this array (size.x = 7, size.y = 4):

  1100111
  1001001
  1111011
  0010000

- with begin = {0, 0}, the function returns 9
- with begin = {6, 0}, the function returns 6
- with begin = {2, 0}, the function returns 4
