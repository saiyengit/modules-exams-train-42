Assignment name  : base_conv
Expected files   : base_conv.c
Allowed functions: write
--------------------------------------------------------------------------------

Write a program that takes three parameters: a number written in base
base_from, then base_from, then base_to. It displays the same number written in
base base_to, followed by a newline.

- base_from and base_to are written in base 10, between 2 and 16 (included).
- The digits are, in increasing order of value: "0123456789abcdef". Uppercase
  letters must also be recognized in the number ("FF" is the same as "ff").
  The output only uses lowercase letters.
- The number can start with one '-'.
- The value of the number always fits in an int.

The parameters are always valid: the number only contains digits allowed by
base_from.

If the number of parameters is not 3, the program just displays a newline.

Examples:

$> ./base_conv "ff" 16 10 | cat -e
255$
$> ./base_conv "255" 10 2 | cat -e
11111111$
$> ./base_conv "-1A" 16 10 | cat -e
-26$
$> ./base_conv "42" 10 16 | cat -e
2a$
$> ./base_conv "0" 7 3 | cat -e
0$
$> ./base_conv "-80000000" 16 10 | cat -e
-2147483648$
$> ./base_conv "42" 10 | cat -e
$
$>
