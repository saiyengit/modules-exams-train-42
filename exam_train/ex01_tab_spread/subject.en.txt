Assignment name  : tab_spread
Expected files   : tab_spread.c
Allowed functions:
--------------------------------------------------------------------------------

Write the following function:

int		tab_spread(int *tab, unsigned int len);

It returns the difference between the largest and the smallest value of the
array of integers tab, whose size is len.

If len is 0 (tab may then be NULL), the function returns 0.

The result always fits in an int.

Examples:

- With {3, 9, -2, 7} (len 4), you will return 11.
- With {-5, -1, -12} (len 3), you will return 11.
- With {42} (len 1), you will return 0.
- With len 0, you will return 0.
