Assignment name  : sym_diff
Expected files   : sym_diff.c
Allowed functions: write
--------------------------------------------------------------------------------

Write a program that takes two strings and displays, without doubles, the
characters that appear in only one of the two strings, followed by a newline.

First display the characters of the first string that are not in the second
one, in the order of the first string. Then display the characters of the
second string that are not in the first one, in the order of the second string.

If the number of parameters is not 2, the program just displays a newline.

Examples:

$> ./sym_diff "bonjour" "journal" | cat -e
bal$
$> ./sym_diff "abc" "def" | cat -e
abcdef$
$> ./sym_diff "aabbcc" "bbddee" | cat -e
acde$
$> ./sym_diff "abc" "abc" | cat -e
$
$> ./sym_diff "solo" | cat -e
$
$>
