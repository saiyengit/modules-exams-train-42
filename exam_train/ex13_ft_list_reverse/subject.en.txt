Assignment name  : ft_list_reverse
Expected files   : ft_list_reverse.c, ft_list.h
Allowed functions:
--------------------------------------------------------------------------------

Write a function that reverses the order of the elements of a list.

You must only change the next pointers: no allocation, and every data stays in
its element. After the call, *begin_list points to what was the last element.

It must be declared as follows:

void	ft_list_reverse(t_list **begin_list);

You must use the following structure, and turn it in as a file called
ft_list.h:

typedef struct		s_list
{
	struct s_list	*next;
	void			*data;
}					t_list;

Example:

"a" -> "b" -> "c" -> "d" -> NULL

becomes:

"d" -> "c" -> "b" -> "a" -> NULL
