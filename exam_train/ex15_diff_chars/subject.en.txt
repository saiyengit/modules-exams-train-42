Assignment name  : diff_chars
Expected files   : diff_chars.c
Allowed functions: write
--------------------------------------------------------------------------------

Write a program that takes two strings and displays, without doubles, the
characters of the first string that do not appear in the second one, in the
order in which they appear in the first string, followed by a newline.

If the number of parameters is not 2, the program just displays a newline.

Examples:

$> ./diff_chars "bonjour" "jour" | cat -e
bn$
$> ./diff_chars "aabbccdd" "bd" | cat -e
ac$
$> ./diff_chars "Hello World" "lo" | cat -e
He Wrd$
$> ./diff_chars "abc" "" | cat -e
abc$
$> ./diff_chars "abc" | cat -e
$
$>
