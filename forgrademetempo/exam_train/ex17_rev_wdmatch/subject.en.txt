Assignment name  : rev_wdmatch
Expected files   : rev_wdmatch.c
Allowed functions: write
--------------------------------------------------------------------------------

Write a program that takes two strings and checks whether it is possible to
write the first string with characters from the second string, reading the
second string from right to left (from its last character to its first one),
while respecting the order of the first string.

If it is possible, the program displays the first string followed by a newline.
Otherwise, it just displays a newline.

If the number of parameters is not 2, the program just displays a newline.

Examples:

$> ./rev_wdmatch "abc" "xcxbxa" | cat -e
abc$
$> ./rev_wdmatch "abc" "abc" | cat -e
$
$> ./rev_wdmatch "nuit" "tiun" | cat -e
nuit$
$> ./rev_wdmatch "quarante deux" "xuedq etnarauq" | cat -e
quarante deux$
$> ./rev_wdmatch "aa" "a" | cat -e
$
$> ./rev_wdmatch "abc" | cat -e
$
$>
