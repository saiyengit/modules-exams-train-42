Assignment name  : ft_interdup
Expected files   : ft_interdup.c
Allowed functions: malloc
--------------------------------------------------------------------------------

Write a function that returns a new string, allocated with malloc, containing
without doubles the characters that appear in both s1 and s2, in the order in
which they appear in s1 (exactly what the program inter displays, but returned
in a string instead).

If no character is common, the function returns an allocated empty string.
s1 and s2 must not be modified. If the allocation fails, the function returns
NULL.

It must be declared as follows:

char	*ft_interdup(char *s1, char *s2);

Examples:

- ft_interdup("padinton", "paqefwtdjetyiytjneytjoeyjnejeyj") returns "padinto"
- ft_interdup("rien", "cette phrase ne cache rien") returns "rien"
- ft_interdup("aaaa", "a") returns "a"
- ft_interdup("abc", "xyz") returns ""
