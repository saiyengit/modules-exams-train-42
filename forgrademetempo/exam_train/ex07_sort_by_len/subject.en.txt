Assignment name  : sort_by_len
Expected files   : sort_by_len.c
Allowed functions: write, malloc, free
--------------------------------------------------------------------------------

Write a program that takes a string and displays its words sorted by length,
from the shortest to the longest, separated by exactly one space, followed by
a newline.

Words that have the same length keep the order in which they appear in the
string.

A word is a section of string delimited by spaces/tabs, or by the start/end of
the string.

If the number of parameters is not 1, or if there is no word, the program just
displays a newline.

Examples:

$> ./sort_by_len "le chat mange une souris" | cat -e
le une chat mange souris$
$> ./sort_by_len "   aaa  bb   c  " | cat -e
c bb aaa$
$> ./sort_by_len "same size word test" | cat -e
same size word test$
$> ./sort_by_len "   " | cat -e
$
$> ./sort_by_len | cat -e
$
$>
