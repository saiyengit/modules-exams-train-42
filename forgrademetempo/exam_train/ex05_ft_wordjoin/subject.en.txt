Assignment name  : ft_wordjoin
Expected files   : ft_wordjoin.c
Allowed functions: malloc
--------------------------------------------------------------------------------

Write a function that returns a new string, allocated with malloc, containing
the words of str in the same order, separated by the string sep.

A word is a section of string delimited by spaces/tabs, or by the start/end of
the string.

Nothing must come before the first word or after the last one. If str has no
word, the function returns an allocated empty string.

The allocation must be exactly the size of the result, '\0' included.

If the allocation fails, the function returns NULL.

It must be declared as follows:

char	*ft_wordjoin(char *str, char *sep);

Examples:

- ft_wordjoin("  vous   voyez  ", " ") returns "vous voyez"
- ft_wordjoin("  vous   voyez  ", "   ") returns "vous   voyez"
- ft_wordjoin("un deux trois", ", ") returns "un, deux, trois"
- ft_wordjoin("seul", "---") returns "seul"
- ft_wordjoin("   ", "-") returns ""
- ft_wordjoin("a b", "") returns "ab"
